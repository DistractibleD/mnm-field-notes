Installing MnM Field Notes
============================

1. Unzip this folder anywhere you like - Desktop, Documents, wherever. No
   installer, no admin rights needed.
2. Double-click "MnMFieldNotes.exe" to launch it. That's it.

A note about the security warning
-----------------------------------
The first time you run MnMFieldNotes.exe, Windows SmartScreen may show a
blue "Windows protected your PC" warning, because this app isn't digitally
signed (a code-signing certificate isn't practical for a small guild tool).
Click "More info" then "Run anyway" - this only appears once. See
README.txt for what the app actually does if you'd like to double-check
first.

What's inside
--------------
- MnMFieldNotes.exe - the app itself. Its icon is built in, used for the
  window and the taskbar.
- ui\ - the window's interface (HTML/CSS/JS), loaded by the app.
- lib\webview2\ - small loader files the app needs to talk to the WebView2
  Runtime (see "If something goes wrong" below). Already included in this
  zip, nothing to download separately.
- README.txt - what the app does and how to use it once it's running.

What shows up after you first run it
---------------------------------------
Two new folders appear next to MnMFieldNotes.exe the first time you launch:
- Data\ - your saved profile name and the running log of everything you log.
  Stays on your computer; nothing here is sent anywhere automatically.
- Sessions\ - one text file per session, written when you click "End session
  & export." Right after, the app offers to submit it straight to the wiki
  for review (opens a pull request - nothing goes live until a human
  approves it) - or you can hand the file to whoever's updating the wiki
  yourself instead, whichever you prefer.

Pinning it to your taskbar
-----------------------------
Right-click MnMFieldNotes.exe and choose "Pin to taskbar" - or run it first
and pin from its icon on the taskbar while it's open. Either way works and
shows the app's own icon, not a generic one.

Removing it
------------
Delete the folder. Nothing else was touched on your computer - no registry
entries, no other install location, nothing to uninstall.

Getting updates
-----------------
The app checks for a newer version automatically when it opens (and any time
via "Check for updates" near the top of the window). If one's available
you'll see a banner with a link to the release page - download that zip and
unzip it the same way you did this one. Your Data\ and Sessions\ folders are
just files, so copy them into the new folder first if you want to keep your
history, or start fresh - either way is fine.

If something goes wrong
--------------------------
If the app shows an error message, check Data\error.log - it has more detail
than the popup does.

If the very first launch fails with a message about the "WebView2 Runtime"
or the embedded browser not starting: this app needs Microsoft's WebView2
Runtime, which ships built into Windows 11 and almost every up-to-date
Windows 10 PC already (it comes with Edge), so this is unlikely - but if it
happens, install it free from Microsoft at
https://developer.microsoft.com/microsoft-edge/webview2/ and try again.
