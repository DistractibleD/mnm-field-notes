# MnM Field Notes

A personal + small-guild companion tool for logging play sessions in *Monsters and Memories* —
combat, gathering, fishing, crafting, and cooking — from a second monitor while you play. See
`README.txt` for what it does and how to use it.

Just want to run the app? You don't need any of this source — grab the zip from the
[latest release](../../releases/latest), unzip anywhere, and run `Start.vbs`. `INSTALL.txt`
inside the zip walks through setup, updates, and removal.

- `latest.json` — current version + download link, read by the app's own update check.
- Releases — each tagged release has the download zip attached as an asset.
