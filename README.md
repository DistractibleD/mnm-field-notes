# MnM Field Notes — Releases

Release artifacts and version-check data for **MnM Field Notes**, a personal companion tool
for logging play sessions in *Monsters and Memories* (combat, harvesting, fishing, crafting,
cooking). This repo holds no application source — just release zips and `latest.json`, which
the app itself checks to let you know when a newer version is available.

- `latest.json` — current version + download link, read by the app's update check.
- Releases — download the zip from the [latest release](../../releases/latest), unzip
  anywhere, and run `Start.vbs`.
